2. 실험 1: 도선은 얼마나 뻣뻣한가 (단계 2)

전기력을 각도로 읽으려면, 먼저 도선의 복원 토크가 비틀린 각에 비례하는지 확인해야 한다. 비례한다면 진폭이 달라도 진동 주기는 같아야 한다.

τ = κ · φ  (복원 토크는 비틀린 각에 비례) T = 2π √(I / κ)  →  κ = 4π² I / T²

실험 방법 ① 2. 비틀림 법칙 단계로 이동한다(탐침구는 빠져 있어 전기력이 없다). ② [10° 돌려 놓기]를 누르고 바늘이 영점을 7회 지나 주기가 표시될 때까지 기다린다. ③ [30°], [60°]로 반복한다. ④ 화면에 표시된 I와 κ를 옮겨 적는다.

4. 분석: 거리 법칙 찾기 (단계 5)

전기력이 F ∝ 1/rⁿ 꼴이라면 양변에 로그를 취했을 때 직선이 되고, 그 기울기가 −n이다.

Θ ∝ 1 / rⁿ  →  log Θ = −n · log r + C

6. 심화: 전기력의 실제 크기 계산

실험 1에서 구한 κ와 실험 2의 Θ를 쓰면 전기력을 뉴턴(N) 단위로 구할 수 있다. 평형에서 도선의 복원 토크 = 전기력의 토크이다. 구는 원호를 따라 움직이므로 전기력 중 원호 방향(접선) 성분 F·cos(θ/2)만 바늘을 돌린다.

κ · Θ(rad) = F · L · cos(θ/2) F = κ · Θ(rad) / [ L · cos(θ/2) ]

Θ는 반드시 라디안으로 바꾼다: Θ(rad) = Θ(°) × π / 180. L = 0.105 m, r은 m 단위로 바꾼다.

계산 예시 (κ = 1.0×10⁻⁷ N·m/rad, α = 120°, θ = 16.5°, Θ = 131.6°) Θ(rad) = 131.6 × π / 180 = 2.297 rad
토크 = 1.0×10⁻⁷ × 2.297 = 2.30×10⁻⁷ N·m
F = 2.30×10⁻⁷ / (0.105 × cos 8.25°) = 2.21×10⁻⁶ N
