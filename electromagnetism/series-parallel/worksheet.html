1찾기 직렬·병렬로 바로 묶을 수 있는 가장 안쪽부터 찾는다. (같은 두 점 사이 → 병렬, 한 줄로 이어짐 → 직렬)

2묶기 하나씩 R′, R″로 바꾸며 회로를 다시 그린다. 저항 하나가 될 때까지 반복.

3전체 I = ε / Req

4되돌리기 묶기의 반대 순서로 펼치며 — 직렬 묶음은 전류가 같고 전압을 나누고(V=IR), 병렬 묶음은 전압이 같고 전류를 나눈다(I=V/R).

Part 1. 단계별 풀이 (빈칸을 채우세요, 계산기를 써도 좋아요)

문제 1 직렬연결 (저항 3개)

1전류는 세 저항에서 (같다 / 다르다)

2Req = R₁ + R₂ + R₃ = = Ω

3I = ε / Req = = A

4V₁ = I·R₁ = V, V₂ = V, V₃ = V

5검산: V₁+V₂+V₃ = V (= ε 이어야 해요)

💡 힌트 직렬은 ‘길’이 하나라서 전류가 같아요. 저항이 큰 곳이 전압을 더 많이 가져가요(분압).

1세 저항에 걸리는 전압은 모두 V

문제 3 혼합연결 A: R₁ + (R₂ ∥ R₃)

1묶기 먼저 병렬인 R₂, R₃ → 1/R′ = → R′ = Ω

2이제 R₁과 R′은 직렬 → Req = = Ω

3전체 전류 I = ε/Req = A (이 전류가 R₁을 지나요)

4되돌리기 V₁ = I·R₁ = V → R₂∥R₃에는 ε−V₁ = V

5I₂ = A, I₃ = A, I₂+I₃ = A ✔

💡 힌트 ‘안쪽부터 묶고, 바깥에서 안쪽으로 되돌아가며 전압·전류를 나눈다’가 핵심이에요.

문제 4 혼합연결 B: (R₁ + R₂) ∥ R₃

1묶기 직렬인 R₁, R₂ → R′ = = Ω

2R′과 R₃은 병렬 → 1/Req = → Req = Ω

3전체 I = ε/Req = A

4되돌리기 두 가지의 전압은 모두 ε = V → 윗가지 전류 I₁₂ = ε/R′ = A, 아랫가지 I₃ = A

5윗가지 안에서 V₁ = I₁₂·R₁ = V, V₂ = I₁₂·R₂ = V

💡 힌트 병렬 묶음의 ‘가지’ 하나가 직렬이면 그 가지는 R′ 하나처럼 계산하고, 나중에 그 안을 다시 풀어요.

문제 5 혼합연결 C: (R₁ ∥ R₂) + (R₃ ∥ R₄)

1R′ = R₁∥R₂ = = Ω

2R″ = R₃∥R₄ = = Ω

3R′과 R″은 직렬 → Req = Ω, I = A

4V′ = I·R′ = V, V″ = I·R″ = V (합 = V)

5I₁ = V′/R₁ = A, I₂ = A, I₃ = A, I₄ = A

💡 힌트 병렬 묶음 두 개가 직렬로 이어졌어요. 묶음마다 ‘전류는 같고 / 전압이 나뉘는’ 직렬 규칙이 적용돼요.

Part 1. (이어서) 어려운 도전 — 직렬·병렬로 안 풀리는 회로

문제 6-① 휘트스톤 브리지 (균형)

1R₁R₄ = = , R₂R₃ = = → 같으면 (균형 / 불균형)

2균형이면 C, D의 전위가 같아서 R₅에 흐르는 전류 I₅ = A → R₅는 없는 셈!

3윗길 R₁+R₃ = Ω, 아랫길 R₂+R₄ = Ω (병렬)

4Req = Ω, I = A

💡 힌트 R₅에 전류가 0이면 R₅를 떼어 내도, 양 끝을 철사로 이어도 결과가 똑같아요. 그래서 ‘직렬 두 줄의 병렬’이 돼요.

문제 6-② 휘트스톤 브리지 (불균형)

1R₄를 30 Ω으로 바꾸면 R₁R₄ = , R₂R₃ = → 같지 않아서 (균형 / 불균형)

2직렬·병렬만으로는 못 묶어요! 접점 C, D의 전위 VC, VD를 미지수로 두고 들어오는 전류 = 나가는 전류(KCL)를 써요. (아래쪽 단자 = 0 V)

  C: (12 − VC)/10 = VC/ + (VC − VD)/

  D: (12 − VD)/ + (VC − VD)/ = VD/

3연립해서 풀면 VC = V, VD = V

4I₅ = (VC−VD)/R₅ = A (C→D 방향), 전체 I = A, Req = ε/I = Ω

💡 힌트 계산이 힘들면 시뮬레이션 ⑬(혼합) 의 ‘휘트스톤 브리지’에서 R₄=30 Ω으로 두고 [다음 ▶]을 눌러 숫자를 맞춰 보세요.
