🕰 단진자 — 뉴턴·라그랑주·해밀턴으로 풀어 보기

관련: 단진자로 g 측정 · 이중진자(혼돈) · 스트로보스코프

📜 흔들리는 추 하나에 담긴 이야기

단진자는 400년 넘게 시계, 지도, 우주관, 음악과 소설에 얽혀 왔어요. 역사·과학·인문·예술 네 갈래로 읽고, 카드 아래 ‘생각해 보기’를 친구와 이야기해 보세요.

※ 연도·수치는 널리 알려진 자료를 바탕으로 정리했어요. 일화로 전해지는 이야기는 그렇다고 표시했습니다. 수업에 쓰기 전 교사가 한 번 더 확인하세요.

🍎 뉴턴의 방법 — 힘을 그리고 ‘F = ma’

추에 작용하는 힘을 하나하나 그리고, 운동 방향(접선)과 줄 방향(반지름)으로 나누어 운동 방정식을 세워요.

※ 말풍선은 과학사 사실을 바탕으로 쉽게 풀어 쓴 학습용 글이며, 실제 발언이 아닙니다.

🎛 추의 위치를 바꿔 보며 힘 분해하기 (m = 1 kg, l = 1 m)

중력 mg장력 T접선 성분 mg sinθ (복원력)줄 방향 성분 mg cosθ

📐 유도 — 뉴턴의 순서

① 힘 찾기중력 mg(아래), 장력 T(줄 방향). 이 둘뿐이에요.
② 접선 방향 (운동 방향)
−mg sinθ = m·(lθ̈)
줄은 접선 방향으로 힘을 못 줘요 → 중력의 접선 성분만 남아 추를 평형점으로 되돌려요.
③ 운동 방정식
θ̈ = −(g/l) sinθ
질량 m이 약분돼요 → 주기는 질량과 무관!
④ 줄 방향 (반지름)
T − mg cosθ = m·lθ̇²
장력은 구심력을 만들고 중력의 줄 방향 성분도 받쳐 줘요 → 최저점에서 가장 커요.
⑤ 에너지로 속도 구하기
lθ̇² = 2g(cosθ − cosθ₀)
T = mg(3cosθ − 2cosθ₀)
⑥ 소각도 근사 sinθ ≈ θ
θ̈ = −(g/l)θ → T₀ = 2π√(l/g)

✨ 라그랑주의 방법 — 힘 대신 에너지로

장력을 따질 필요 없이 운동에너지 T와 퍼텐셜에너지 V만 쓰면 같은 운동 방정식이 나와요. 움직임을 나타낼 좌표를 마음대로 고를 수 있어요(일반화 좌표).

※ 말풍선은 학습용으로 재구성한 글이며 실제 발언이 아닙니다.

📈 퍼텐셜 V(θ)와 근사 포물선 (단위: mgl)

V = mgl(1−cosθ)근사 ½mglθ²전체 에너지 E

📐 유도 — 라그랑주의 순서

① 좌표 고르기줄 길이가 일정하다는 조건 덕분에 각도 θ 하나면 충분해요(자유도 1).
② 에너지 쓰기
T = ½ml²θ̇², V = mgl(1 − cosθ)
③ 라그랑지안
ℒ = T − V = ½ml²θ̇² − mgl(1 − cosθ)
④ 오일러–라그랑주 방정식
d/dt(∂ℒ/∂θ̇) − ∂ℒ/∂θ = 0
∂ℒ/∂θ̇ = ml²θ̇, ∂ℒ/∂θ = −mgl sinθ
⑤ 결과
ml²θ̈ + mgl sinθ = 0 → θ̈ = −(g/l) sinθ
뉴턴의 방법과 똑같은 식! 장력은 한 번도 등장하지 않았어요.

🔎 왜 굳이 라그랑주?

  • 줄이 하는 일처럼 구속력을 몰라도 돼요.
  • 좌표가 각도든 길이든 같은 절차로 풀려요.
  • 이중진자·행성계처럼 복잡한 계도 ℒ만 쓰면 시작할 수 있어요.
  • ‘θ가 식에 없으면 ∂ℒ/∂θ = 0 → ∂ℒ/∂θ̇는 보존’ 같은 보존량을 대칭에서 찾게 해 줘요.

🌀 해밀턴의 방법 — 위치와 운동량의 ‘위상 공간’

위치 θ와 운동량 p를 짝으로 놓고, 전체 에너지 H 하나가 상태의 변화를 모두 결정한다고 보는 방법이에요. 진자의 모든 운동이 한 장의 지도(위상 초상)에 담겨요.

※ 말풍선은 학습용으로 재구성한 글이며 실제 발언이 아닙니다.

🗺 위상 초상 — 가로: 각도 θ, 세로: 각속도 θ̇/ω₀ (p에 비례)

에너지 등고선(가능한 운동)분리선 (꼭대기에 닿는 경계)지금 운동근사 운동(원)

📐 유도 — 해밀턴의 순서

① 운동량 정의
p = ∂ℒ/∂θ̇ = ml²θ̇
② 해밀토니안 (=전체 에너지)
H = pθ̇ − ℒ = p²/(2ml²) + mgl(1 − cosθ)
③ 해밀턴 방정식 (1계 방정식 두 개)
θ̇ = ∂H/∂p = p/(ml²)
ṗ = −∂H/∂θ = −mgl sinθ
④ 합치면θ̈ = ṗ/(ml²) = −(g/l) sinθ — 앞의 두 방법과 같은 식이에요.
⑤ 위상 초상 읽기H가 일정 → 운동은 H = 일정인 곡선 위만 움직여요. 닫힌 곡선=진동, 분리선 바깥의 물결선=계속 돌기, 분리선=꼭대기에서 멈출 듯 넘어가는 경계.

🔎 이렇게 생각해 보세요

  • 진폭이 작으면 곡선이 타원(원)에 가까워요 → 단순조화운동.
  • 진폭이 커질수록 곡선이 찌그러져 한 바퀴 도는 시간이 늘어요.
  • 해밀턴 흐름은 위상 공간의 넓이를 보존해요(리우빌 정리). 통계역학·양자역학으로 이어지는 출발점이에요.

⚖ 진짜 진자의 해 vs 소각도 근사 해

세 방법이 똑같이 도착한 식 θ̈ = −(g/l) sinθ 는 풀기 어려운 비선형 식이에요. sinθ를 θ로 바꾼 근사 해와 실제 해는 얼마나 다를까요? 그리고 교실의 진짜 진자는 또 어떻게 다를까요?

※ 말풍선은 학습용으로 재구성한 글이며 실제 발언이 아닙니다.

〰 각도–시간 그래프 (시간 단위: 근사 주기 T₀)

근사 해 θ₀cos(ω₀t)정확한 해(수치 적분)실제처럼 감쇠 있는 진자

📐 정확한 주기

T = 4√(l/g)·K(sin(θ₀/2))
T ≈ T₀ [1 + θ₀²/16 + 11θ₀⁴/3072 + …]

K는 ‘제1종 완전 타원적분’이에요. 초등함수로는 표현이 안 돼서 수치 계산(또는 급수)을 써요. 아래 그래프에서 진폭이 커질수록 실제 주기가 근사값 T₀ = 2π√(l/g) 보다 길어지는 모습을 보세요.

정확한 T/T₀1항 보정 1+θ₀²/16근사 T/T₀ = 1

📋 진폭에 따른 주기 오차 (정확한 값은 산술-기하 평균 AGM으로 계산)

‘근사 주기 오차’ = (T₀ − T) / T. 근사 해는 실제보다 항상 주기를 짧게 예측해요. 진폭이 클수록 오차가 급하게 커져요.

🏫 교실의 진짜 진자는 이상적인 진자와 무엇이 다를까?

① 추의 크기

점이 아니라 반지름 r인 공이면 관성모멘트가 커져 주기가 길어져요. 구: T = T₀√(1 + 2r²/5L²), L은 지지점~공 중심 거리.

② 줄의 질량·신축

줄이 무겁거나 늘어나면 L이 달라져요. 가볍고 늘어나지 않는 낚싯줄·실이 좋아요.

③ 공기저항·마찰

진폭이 서서히 줄어요(그래프의 초록 선). 주기는 아주 조금만 길어져서 짧은 시간 측정엔 영향이 작아요.

④ 지지점 흔들림

스탠드가 흔들리면 에너지가 새고 주기가 변해요. 단단히 고정하고, 실이 미끄러지지 않게 해요.

⑤ 큰 진폭

위 표처럼 10° 이하에서는 오차 0.2 % 이하지만 60°에서는 약 7 %예요.

⑥ 장소에 따른 g

위도·고도에 따라 g가 0.5 % 정도 달라요(극 9.83, 적도 9.78 m/s²). 푸코 진자의 지구 자전도 아주 미세한 효과예요.

🕹 시뮬레이션 — 힘과 에너지를 눈으로 확인

정확한 비선형 식(RK4)으로 움직여요. 최고점·중간·최저점에서 멈추면 힘 분해와 에너지 변환을 볼 수 있어요. 큰 각도로 놓고 ‘주기(측정)’이 ‘주기(근사)’와 얼마나 다른지 확인해 보세요.

🔬 예비 실험 — 본 실험 전에 확인할 것

예비 1. 변인 통제 ‘눈으로’ 확인하기 (10분)
  1. 실 길이 1 m로 고정. 처음 각도 10°로 놓고 왕복 10번이 걸리는 시간을 재요.
  2. 각도만 30°로 바꿔 다시 재요. (질량·길이는 그대로)
  3. 이번엔 추를 다른 것으로 바꿔 10°에서 재요. (각도·길이는 그대로)
  4. 마지막으로 길이만 바꿔 재요 (0.25 m, 1 m).

예측 먼저! 어떤 변인이 시간을 바꿀 것 같나요? 결과가 예측과 달랐다면 왜일까요?

예비 2. 스톱워치 반응시간과 측정 방법 점검
  1. 친구가 자를 잡았다 놓고, 내가 떨어지는 자를 잡아 떨어진 거리 d를 읽어요 (5회 평균).
  2. 반응시간 t = √(2d/g). 아래 계산기로 구해요. (보통 0.15~0.25 s)
  3. 같은 주기를 1주기와 10주기로 재면 반응시간 오차가 각각 몇 %인지 비교해요.

반응시간 오차 ≈ 0.2 s라면, 주기 2 s를 1주기만 재면 약 10 %, 10주기(20 s)를 재면 약 1 %예요.

예비 3. 길이 재는 법 · 지지점 만들기
  • 길이 l = (지지점에서 매듭까지) + (추 반지름). 추의 중심까지가 기준이에요.
  • 클램프 두 개 사이(또는 반으로 갈라 낀 코르크 사이)에 실을 끼우면 지지점이 일정하고 실이 미끄러지지 않아요.
  • 진자를 한 평면 안에서만 흔들리게 놓는 연습을 해요(원뿔 운동 방지).
예비 4. 타이밍 잡는 법
  • 빠르게 지나가는 평형점(최저점)에 기준선을 두고, 추가 기준선을 같은 방향으로 지나는 순간마다 하나씩 세요.
  • 처음 1~2번은 세지 않고 흔들림이 안정된 뒤에 시작 버튼을 눌러요(0부터 센다).

🧭 본 실험 방법

실험 1 · 주기와 진폭l = 1.00 m, 같은 추. θ₀ = 5°, 10°, 15°, 20°, 30°, 45°에서 각각 10주기 시간을 3회 재요. T = (10주기 시간)/10 → 어느 각도부터 T가 눈에 띄게 늘어나는지 5번 탭 표와 비교.
실험 2 · 주기와 질량l = 1.00 m, θ₀ = 10° 고정. 질량이 다른 추 3개로 T 측정 → 질량이 달라도 T가 같은가? (추 크기가 다르면 보정 필요)
실험 3 · 주기와 길이, 그리고 gθ₀ = 10° 고정. l = 0.30, 0.45, 0.60, 0.75, 0.90, 1.05 m로 바꿔 T 측정 → T² – l 그래프의 기울기 = 4π²/g → g = 4π²/기울기.
💡 그래프를 직선으로 만드는 비밀: T = 2π√(l/g) 의 양변을 제곱하면 T² = (4π²/g)·l. 원점을 지나는 직선이에요. 원점을 안 지나면 길이 측정(중심 위치)에 체계적 오차가 있다는 신호!

🧮 내 데이터로 g 구하기

l (m)10주기 시간 (s)T (s)T² (s²)

l과 10주기 시간을 입력하면 최소제곱 직선을 그려 줘요. 기준값 g = 9.80 m/s²와 비교한 오차율도 계산해요. (예시 데이터는 시뮬레이션 값이며 실제 측정이 아니에요)

🧮 결과 미리 어림하기 (보정 계산기)

L = a + r (지지점~공 중심). ① T₀ = 2π√(L/g) ② 공 크기 보정 √(1 + 2r²/5L²) ③ 진폭 보정 1/AGM(1, cos(θ₀/2)). 본 실험의 측정 주기와 비교해 어떤 보정이 큰지 살펴보세요.

🔍 오차는 어디서 올까? (보고서 ‘고찰’에 쓸 거리)

  • 체계적 오차: 길이를 줄 끝까지로 재기, 공 중심 위치, 진폭이 너무 큼, 줄 늘어남, 지지점 이동.
  • 우연 오차: 반응시간, 주기 세다가 놓침, 평면이 아닌 원뿔 운동.
  • 줄이는 법: 10주기 이상 측정·반복 평균, 작은 각도, 단단한 지지점, 영상/포토게이트 활용.

더 해볼 거리: 길이를 다르게 해 두 진자를 같이 놓고 위상이 어긋나는 모습 관찰하기 · 진자의 감쇠(진폭이 반으로 줄 때까지 몇 번 흔들리나?) 측정하기 · 푸코 진자가 있는 과학관 찾아가 보기.
