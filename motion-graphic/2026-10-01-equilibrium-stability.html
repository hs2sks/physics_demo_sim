알짜힘
알짜힘 = 5 N − 3 N = 2 N → 오른쪽
알짜힘 = 0 → 힘의 평형
정지해 있거나, 일정한 속도로 움직인다 (가속도 = 0)
돌림힘 — 문은 어디를 밀어야 쉬울까?
위에서 내려다본 문 · 같은 힘 F로 민다
① r = 0.5 m → τ = 0.5 m × F
② r = 1.0 m → τ = 1.0 m × F
같은 시간 동안 2배 더 돌아간다
τ = r F
회전축에서 멀리, 수직으로 밀수록 돌림힘이 크다
돌림힘의 이용 — 지레
받침점을 회전축으로, 무거운 돌을 들어 올리려면?
600 N × 0.5 m = 200 N × 1.5 m
0 N·m = 0 N·m
팔이 3배 길면, 힘은 1/3이면 충분하다
평형 — 시소를 수평으로 맞추려면?
왼쪽 돌림힘: 500 N × 1.2 m = 600 N·m
오른쪽 돌림힘: 300 N × 1.00 m = 300 N·m
→ 왼쪽으로 기운다
ΣF = 0
위아래로 움직이지 않는다 · 800 N = 500 N + 300 N
Στ = 0
회전하지 않는다 · 600 N·m = 600 N·m
안정성 — 왜 높은 상자가 잘 넘어질까?
두 상자를 모서리를 축으로 똑같이 22° 기울였다가 놓으면?
무게중심은 낮게, 받침면은 넓게
높은 상자
낮은 상자
연직선이 받침면 밖 → 넘어진다
연직선이 받침면 안 → 되돌아온다
문제 풀이 — 사람이 어디까지 가면 기울어질까?
판자 4 m · 200 N │ 받침 A(0 m), B(3 m) │ 사람 400 N
NA = 333 N │ NB = 267 N
사람 위치 = 1.00 m (A 기준)
기울어지기 직전 → N_A = 0
① NA = 0이니까, B를 회전축으로 잡는다
② 200 N × 1 m = 400 N × x
③ x = 0.5 m → B에서 오른쪽 0.5 m (A에서 3.5 m)
④ ΣF = 0 → NB = 200 N + 400 N = 600 N
요령: 기울어지기 직전 → 떨어지는 쪽 수직항력 = 0, 남은 받침점을 회전축으로!
정리
1  알짜힘 = 0 → 힘의 평형
2  τ = r F (회전축까지 거리 × 힘)
3  평형 조건: ΣF = 0, Στ = 0
4  무게중심 연직선이 받침면 안 → 안정
풀이 3단계
① 물체에 작용하는 힘을 모두 그린다
② 모르는 힘이 걸린 점을 회전축으로
③ ΣF = 0, Στ = 0 식을 세운다
