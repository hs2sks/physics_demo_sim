문항 1: 나란히 놓고 비교한다
결론
둘 다 축적이 어느 시점에 급격한 변화를 낳지만 결과가 파괴와 발전으로 다르다.
유사
축적 → 한 지점 → 급변
차이
(결과) (가) 회복 불가·파괴　↔　(나) 새 이론·발전 → 재축적
ex
지진: 판 경계 에너지 축적 → 마찰력 초과 → 방출 = (가)형
나비 변태 = (나)형
유사점은 구조(축적 → 한 지점 → 급변)로, 차이점은 결과로 — 그래야 문항 3의 단어로 이어집니다.
문항 2: 두 관점으로 나눠 평가한다
(가) 관점
갈등 · 차별 · 불평등 축적 → 사회 분열 (파괴)
(나) 관점
노동력 · 문화 다양성 축적 → 경쟁력 · 성숙 (발전)
종합 ∴
문화 감수성 + 정착·통합 정책 → 건설적 방향
장단점을 나열하지 않고, (가)의 파괴 / (나)의 발전 관점으로 나누고 종합 의견을 따로 냅니다.
문항 3: 단어를 함수에 대입한다
결론
단어는 임계점이고, 함수에서는 극점과 변곡점이다.
함수
원점 대칭: g(x)=x³+cx → f(x)=(x−2)³+c(x−2)+5
f(4)=7: 8+2c+5=7 → c=−3
적용
f′=3(x−2)²−3=0 → 극점 x=1, 3　/　변곡점 x=2
맺음 ∴
증가 ↔ 감소가 바뀌는 지점 = 임계점
계산이 끝이 아닙니다 — 구한 극점 · 변곡점이 왜 “임계점”인지 단어와 이어 말합니다.
이렇게 한 장이 완성된다
찾을 것 1: ①유사 ②차이 ③자연현상　2: ①(가) 관점 ②(나) 관점 ③종합
　　　　 3: ①단어 ②f(x) ③설명◀ 맨 위: 찾을 것 목록
(가) 변화 요인 축적 → 회복 불가 시점 → 파국
(나) 연구 축적 → 결정적 발견 → 새 이론 → 재축적
(다) 인구 이동 ↑ → 다문화 사회
(라) 3차, 최고차 1, f(4)=7, (−2,−5) 이동 → 원점 대칭◀ 제시문마다 한 줄 요지
1 축적 → 한 지점 → 급변 / 차이: 파괴 ↔ 발전 / ex 지진 · 나비
2 (가) 갈등 축적 → 분열　(나) 다양성 축적 → 성숙 ∴ 통합 정책
3 단어 = 임계점 / f(x)=(x−2)³−3(x−2)+5 / 극점 1·3 변곡점 2◀ 문항별 뼈대
