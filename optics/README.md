- 반사·굴절과 스넬 법칙
- 렌즈와 상(볼록/오목 렌즈 작도) — 볼록 렌즈 `convex-lens/` 완료 (광선 추적·실상/허상)
- 파동의 간섭 (이중슬릿) — `double-slit/` 완료 (경로차·무늬 간격·슬릿 폭 a 반영(회절 포락선). 11/09 리뉴얼: 영 안내·미션·3탭, ③탭에서 이중/단일 슬릿·회절격자·용수철(나선: 층선·X자·DNA형 이중나선) 실측과 이론 비교. 수업 덱 임베드 ?embed=1&a= 유지)
- 뉴턴 링 박막 간섭 — `newton-rings/` 완료 (스마트폰 사진 분석·보고서)
- 회절
- 빛 공방 — `light-workshop/` 협력 보드게임(1막 간섭·2막 굴절·3막 이중성 완료). 서버 API는 board 앱 `light_game.py`, 교사 화면은 `board.crazyray.uk/admin/lightgame`
- 편광
- 도플러 효과

- `common/og.css`·`og.js` — 과학자 안내(말풍선)·사용 방법·미션 체크·실제 사진 비교 컴포넌트. 간섭·빛의 속도(+뢰머·피조·푸코)·마이컬슨-몰리·뉴턴 링이 사용.
- `assets/people/`, `assets/photos/` — Wikimedia Commons 퍼블릭 도메인·CC 이미지(출처·라이선스 `assets/credits.json`, 각 페이지에도 표기). CC BY-SA 이미지는 출처 표기 유지.
