    장치무늬 모양조건줄 사이 간격
    이중 슬릿밝기가 비슷한 줄무늬가 여러 개 (바깥은 회절 곡선 안에서만)밝음: d sinθ = mλΔy ≈ λL/d
    단일 슬릿가운데가 가장 밝고 넓은 띠, 옆은 약한 띠어둠: a sinθ = mλ (m=1,2,…)가운데 띠 폭 ≈ 2λL/a
    회절격자가늘고 선명한 밝은 점·줄이 멀리 떨어져 나타남밝음: d sinθ = mλ, d = 1/(줄 수)선 수가 많을수록 더 멀리
    용수철코일 사이 틈이 격자 역할 → 점이 일정 간격으로 늘어섬밝음: p sinθ = mλ (p = 피치)Δy ≈ λL/p
