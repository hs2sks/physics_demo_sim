# PRD — 빛의 속도 측정 (과학사적 접근)

## 5W1H

| 항목 | 내용 |
|---|---|
| Why | "빛의 속도는 유한한가? 얼마인가?"를 과학자들이 400년에 걸쳐 밝혀낸 과정을 체험. 측정 정밀도가 어떻게 발전했는지 |
| What | 역사적 측정법 4가지 — 갈릴레이(랜턴), 뢰머(목성 위성 이오), 피조(톱니바퀴), 푸코(회전거울) |
| Who | 물리학I·II, 융합과학탐구. 광학·과학사 연계 |
| When | 광학 단원 도입/심화, 과학사 수업 |
| Where | 프로젝터 시연 + 학생 개별 탐구 (반응형) |
| How | 탭별 인터랙티브: 매개변수 슬라이더 → 측정 원리 애니메이션 → c 계산 → 현대값(299,792,458 m/s)과 비교 |

## 방법별 핵심 원리

1. **갈릴레이 (1638)** — 두 언덕 랜턴 신호. 빛 왕복시간(2L/c)이 사람 반응시간(~0.2s)보다 훨씬 짧아 측정 실패 → "빛은 매우 빠르거나 즉각적". 거리 슬라이더로 두 시간을 비교해 왜 실패하는지 체감.
2. **뢰머 (1676)** — 목성 위성 이오의 식(蝕) 시각이 지구-목성 거리에 따라 늦어짐. 지구 공전궤도 지름(≈2.99×10¹¹ m)을 빛이 가로지르는 시간(≈16.6분)이 누적 지연으로 나타남. c = 지름 / 최대지연.
3. **피조 (1849)** — 회전 톱니바퀴 틈으로 나간 빛이 먼 거울(L)에 반사돼 돌아올 때, 특정 회전수에서 다음 톱니에 막힘(식). c = 4·L·n·f (n=톱니수, f=회전수). 학생이 첫 식이 일어나는 회전수를 찾아 c 계산.
4. **푸코 (1862)** — 회전거울에 반사된 빛이 왕복하는 동안 거울이 조금 돌아, 돌아온 빛이 각도 편향. 편향각 = 4ωD/c. 물속에서 c가 더 느림을 보여 파동설 지지.

## 완성 기준

- 각 방법의 계산식이 현대값과 오차 범위 내로 일치 (피조·푸코는 슬라이더 위치에서 c = 4Lnf, 4ωD/편향각 이 참값 복원)
- 개요 탭에 역사적 측정값 타임라인 + 현대 정의값(1983년 이후 c는 정의 상수) 제시
- 홈 버튼, 프로젝터(큰 글씨) 모드, 모바일 반응형

## 오개념 대비

- "빛은 무한히 빠르다(즉각 도달)" → 갈릴레이 실패 + 뢰머의 유한 속도 발견으로 반박
- "빛의 속도는 처음부터 정확히 알려졌다" → 측정값이 점차 정밀해진 타임라인으로 교정
