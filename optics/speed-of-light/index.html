🌠 빛의 속도 측정 — 과학자들의 도전

빛은 순식간에 도달할까요, 아니면 유한한 속도로 달릴까요? 이 물음에 답하기까지 약 250년이 걸렸습니다. 측정이 정밀해지면서 오늘날 빛의 속도는 측정하는 값이 아니라 정의된 상수가 되었습니다.

현대 정의값   c = 299 792 458 m/s (정확)

1983년부터 1 m는 “빛이 진공에서 1/299 792 458초 동안 가는 거리”로 정의됩니다.

⏳ 누가, 어떻게, 얼마나 정확하게? (초록 세로선 = 현대값, 인물을 누르면 그 실험으로)

※ 값은 널리 인용되는 어림값이며 출처에 따라 조금씩 다릅니다. 브래들리·마이컬슨은 별도 실험 페이지가 없습니다.

내가 측정한 방법구한 c (km/s)현대값과의 차이

랜턴 신호법 1638

  1. 두 언덕 사이 거리를 바꿔 봅니다.
  2. 랜턴 신호 보내기를 눌러 신호가 오가는 모습을 봅니다.
  3. 아래 결과에서 빛의 왕복 시간 vs 사람 반응 시간을 비교합니다.
빛 왕복 시간 = 2L / c

갈릴레이는 먼 언덕의 조수가 불빛을 보는 즉시 자기 등불을 열게 해서, 왕복 시간을 재려 했습니다. 하지만 사람의 반응 시간(약 0.2초)이 빛의 왕복 시간보다 압도적으로 길어서 측정이 불가능했습니다.

📖 갈릴레이는 《두 새로운 과학》(1638)에 이 시도를 적고, “빛이 순간적이지는 않아도 극도로 빠르다”고 결론지었습니다. 실험은 ‘실패’했지만 ‘빛의 속도는 재 볼 수 있는 물음’으로 바뀌었습니다.
0: 목성에 가장 가까움6: 가장 멂
사용할 자료

목성 위성 이오의 식 1676

  1. 슬라이더를 0 → 6개월로 천천히 옮기며 지구가 목성에서 멀어지는 것을 봅니다.
  2. 멀어질수록 이오의 식이 늦게 관측되는 시간(누적 지연)이 늘어나는 것을 확인합니다.
  3. 6개월에서 c = 궤도 지름 ÷ 최대 지연을 계산하고, 두 가지 자료를 바꿔 비교합니다.
c = 궤도 지름 D / 최대 지연 Δt

이오는 약 1.77일마다 목성 뒤로 숨는 식을 반복합니다. 뢰머는 이 간격이 지구가 목성에서 멀어질 때 점점 늦어지는 것에 주목했습니다.

📖 뢰머는 1676년 파리에서 “11월 9일의 식은 계산보다 약 10분 늦을 것”이라고 예고했고 그대로 되었습니다. 그가 직접 c를 계산한 것은 아니며, 하위헌스가 지연 약 22분으로 약 22만 km/s를 얻었습니다. (오늘날 지연은 약 16.6분)

회전 톱니바퀴 1849

  1. 회전수를 0에서 천천히 올립니다. 돌아온 빛의 밝기를 살핍니다.
  2. 밝기가 처음으로 0%가 되는 회전수(첫 식)를 찾습니다.
  3. 그 값을 c = 4·L·n·f 에 넣어 빛의 속도를 얻습니다.
c = 4 · L · n · f식

회전이 느리면 빛은 같은 틈으로 돌아오고, 회전수를 올리면 돌아온 빛이 다음 톱니에 막힙니다(식). 막히는 순간 빛이 왕복하는 동안 바퀴가 틈 반 칸만큼 돌았다는 뜻이라, 왕복 시간 2L/c = 1/(2nf) 에서 c를 얻습니다.

📖 피조는 1849년 파리 교외 쉬렌(Suresnes)의 집에서 몽마르트르 언덕의 거울까지 8 633 m를 이용했고, 톱니 720개의 바퀴가 초당 약 12.6바퀴일 때 첫 식을 관측해 약 313 000 km/s를 얻었습니다. 지상에서 잰 최초의 값입니다.

회전거울 1862

  1. 회전수를 올려 돌아온 빛이 비껴 나가는 모습을 봅니다.
  2. 편향 읽기를 여러 번 눌러 보세요. 눈금을 읽을 때마다 조금씩 다른 값이 나옵니다.
  3. 여러 번 잰 평균이 참값에 가까워지는지 확인합니다.
편향각 δ = 4ωD / c  →  c = 4ωD / δ

빛이 회전거울 → 고정거울 → 회전거울로 왕복하는 동안 거울이 조금 돌아가서, 돌아온 빛은 원래 길에서 살짝 비껴 나옵니다. 이 아주 작은 각도를 잴 수 있다면 c를 알 수 있습니다.

📖 푸코는 1862년 이 방법으로 약 298 000 km/s를 얻었습니다. 좁은 실험실에서도 되는 방법이었고, 1850년에는 같은 장치로 물속에서 빛이 더 느리다는 것을 보여 빛의 파동설을 뒷받침했습니다.
