🌠 빛의 속도 측정 — 과학사

빛이 순식간에 도달하는지, 아니면 유한한 속도로 달리는지 — 이 물음에 답하기까지 약 250년이 걸렸습니다. 측정 정밀도는 점점 높아져, 오늘날 빛의 속도는 측정하는 값이 아니라 정의된 상수가 되었습니다.

현대 정의값   c = 299 792 458 m/s (정확)

1983년부터 1 m는 "빛이 진공에서 1/299 792 458 초 동안 가는 거리"로 정의됩니다. 즉 c는 더 이상 오차가 없습니다.

랜턴 신호법 1638

갈릴레이는 두 언덕에서 조수와 마주 서서, 한쪽이 등불을 열면 다른 쪽이 그것을 본 즉시 자기 등불을 열게 하고, 빛이 왕복하는 시간을 재려 했습니다.

빛 왕복 시간 = 2L / c

문제는 사람의 반응 시간(약 0.2초)이 빛의 왕복 시간보다 압도적으로 크다는 것. 거리를 아무리 늘려도 반응 시간에 묻혀 버립니다.

거리 슬라이더를 최대로 올려도 빛 왕복 시간은 여전히 반응 시간의 수천분의 1입니다. 갈릴레이는 "빛이 즉각적이지는 않은 것 같지만, 매우 빠르다"는 결론에 그쳤습니다.

0개월: 지구가 목성에 가장 가까움 · 6개월: 가장 멀어짐(궤도 반대편)

목성 위성 이오의 식 1676

목성의 위성 이오는 약 1.77일마다 목성 뒤로 숨었다 나오는 식(蝕)을 반복합니다. 뢰머는 지구가 목성에서 멀어질 때 식이 점점 늦게 관측되는 것을 발견했습니다.

지구가 반 바퀴 도는 동안 늦어진 총 시간은, 빛이 지구 공전궤도의 지름을 가로지르는 데 걸리는 시간입니다.

c = 궤도 지름 D / 최대 지연 Δt

이것이 빛의 속도가 유한함을 보인 최초의 증거입니다. (뢰머 자신은 c를 명시적으로 계산하진 않았고, 하위헌스가 그 값으로 계산했습니다.)

회전 톱니바퀴 1849

피조는 빠르게 도는 톱니바퀴의 틈으로 빛을 내보내, 멀리(L=8.6 km) 있는 거울에 반사시켜 되돌아오게 했습니다.

회전이 느리면 빛은 같은 틈으로 돌아오지만, 회전수를 높이면 돌아온 빛이 다음 톱니에 막혀(식) 사라집니다.

c = 4 · L · n · f식

밝기 막대가 처음으로 0이 되는 회전수 f를 찾아 위 식에 넣으세요. 지상 실험실에서 빛의 속도를 잰 최초의 측정입니다.

회전거울 1862

푸코는 빛을 회전하는 거울에 맞춰, 멀리 있는 고정 거울로 보냈다 되돌렸습니다. 빛이 왕복하는 짧은 시간 동안 회전거울이 조금 돌아가, 돌아온 빛은 원래 경로에서 살짝 비껴 나갑니다.

편향각 = 4 ω D / c  →  c = 4 ω D / 편향각

이 방법은 좁은 실험실에서도 가능했고, 특히 물속에서 빛이 더 느림을 보여 빛의 파동설을 뒷받침했습니다.

ω는 각속도(2πf). 편향각이 아주 작아 화면에서는 과장해 표시합니다.
