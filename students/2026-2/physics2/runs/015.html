03 / THE LIGHT POSTULATE

B의 관성계에서도
빛은 왜 c일까요?

빛의 속력은 관찰자의 운동을 단순히 빼서 구하지 않습니다. 속도는 방향을 가진 벡터이고, 좌표계를 바꾸면 성분과 시간이 함께 바뀝니다.

핵심은 빛의 속력이 아니라 방향과 성분이 달라진다는 것입니다.

A계에서 q를 향하는 빛은 수직이므로 ux = 0, uy = c입니다. B는 +x로 움직이므로, B계에서는 광선이 왼쪽 위 대각선으로 보입니다.

속도 변환 결과 u′x = (ux − v)/(1 − vux/c²) = −v
u′y = uy/[γ(1 − vux/c²)] = c/γ
|u′| = √(v² + c²/γ²) = c

γ = 1/√(1 − v²/c²)이므로 v² + c²/γ² = v² + c² − v² = c²입니다. x 성분만 보고 c − v라고 하면 빛의 속력이 관성계마다 달라지는 잘못된 결론이 나옵니다.

광속 불변 원리: 모든 관성계의 관찰자는 진공에서 빛의 속력을 c로 측정합니다. B계의 대각선 경로와 시간 지연은 이 원리와 서로 모순되지 않습니다.

04 / PROPER LENGTH

경로의 길이와 두 점 사이의 거리는 다릅니다.

시간을 비교할 때는 각 광선의 출발 사건부터 도달 사건까지를 비교합니다. 길이 수축은 같은 시각에 잰 물체 양 끝의 거리입니다.

동시에 잰 광원과 표적 사이 간격γ = 1.12
A계 · S-P 고유 길이 L₀
B계 · S-P (x방향) L₀/γ = 0.89 L₀
B계 · S-Q (y방향) L₀

B계에서 S-P는 짧고, S-Q는 그대로입니다.

S-P는 운동 방향과 나란하므로, B계에서 같은 시각에 잰 길이는 L₀/γ입니다. S-Q는 운동 방향에 수직이므로 길이 수축을 하지 않습니다.

L′SP = L₀/γ   ≤   L′SQ = L₀

중요: q까지 빛이 간 대각선 경로 γL₀는 S-Q의 간격 L₀가 아닙니다. γL₀는 빛이 출발과 도달 사이에 실제로 지나간 경로이고, L₀는 같은 시각에 잰 세로 간격입니다.

광원에서 빛을 쏜 뒤, 표적에 닿기까지의 좌표 시간
관성계 Ap: L₀/cq: L₀/c
관성계 Bp: L₀/[γ(c + v)]q: γL₀/c

B계에서 p는 −x 방향으로 빛을 향해 움직입니다. 따라서 Δt′p = (L₀/γ)/(c + v)입니다. q의 출발·도달 사건은 A계에서 ΔxA = 0이므로 Δt′q = γΔtA입니다.

빛이 실제로 간 거리는 d′p = cΔt′p = L₀/[γ(1 + β)], d′q = cΔt′q = γL₀입니다. β > 0이면 q 광로가 더 깁니다. p는 빛을 향해 움직이므로 d′p는 처음의 동시 간격 L₀/γ보다 짧습니다.

주의: S→q 한 번의 비행은 한 시계의 고유시간이 아니라 두 사건의 시간 변환 결과입니다. 움직이는 B 시계의 시간 지연은 ΔtA = γΔτB로 나타냅니다.

모형 가정: A계에서 광원 S, p, q는 정지하고 SP = SQ = L₀입니다. B는 +x 방향으로 일정한 속력 v로 운동합니다. 그림의 공간 단위와 시간은 각각 L₀, L₀/c로 정규화했습니다.
