🧪 보일·샤를 법칙 가상 실험실

물리실험노트 「6. 보일의 법칙·샤를의 법칙」을 가상으로 해 봅니다. 눈금과 온도를 직접 읽어 표에 입력하면 그래프와 오차가 계산됩니다. 교실에서 잰 실제 값을 표에 넣어도 같은 방식으로 분석됩니다.

모둠마다 장치 상태(오차 원인)가 다릅니다. 같은 번호는 같은 장치를 불러옵니다. 오차 원인은 ⑤ 단계에서 확인합니다.
① 실험 안내 — 압력이 일정할 때 공기의 부피와 온도
  1. 공기기둥(약 8 cm)을 가둔 가는 유리관이 눈금자 옆에 고정되어 있습니다. 관 전체가 물에 잠겼는지 먼저 살펴봅니다.
  2. 얼음물에서 시작합니다. 공기기둥 아래쪽 끝의 눈금을 읽어 아래 칸에 적습니다(한 번만).
  3. 불을 약하게 켜 물을 데우고, 원하는 온도 근처에서 불을 끈 뒤 저으면서 수은이 완전히 멈추기를 기다립니다.
  4. 멈춘 뒤 수온 t와 공기기둥 위쪽 끝(수은 마개 아래 면)의 눈금을 확대 창에서 읽어 표에 입력합니다.
  5. 온도를 조금씩 올리며 80 ℃ 이하에서 6점 이상 반복합니다.
  6. 분석: l–t 그래프의 가로축 절편 t₀, 0 ℃ 길이 l₀, 부피팽창률 α = (l − l₀)/(l₀·t)의 평균을 구하고 기준값 1/273 ≈ 3.66×10⁻³ /℃와 비교합니다.

② 가상 장치

불세기

③ 측정값 입력

입력한 값은 이 브라우저에만 저장됩니다(모둠 번호별).

④ 분석

● 입력한 점 / 빨간 선 = 최소제곱 직선(가로축까지 연장) / 회색 점선 = 오차 없는 이상적인 공기(t₀ = −273.15 ℃)
직선에서 벗어난 정도(잔차, mm). 측정한 순서대로 나열되어 있습니다.

자료에서 읽을 수 있는 단서

    ⑤ 오차 원인 찾기

    이 모둠의 장치에는 아래 중 네 가지가 있습니다. 위 그래프와 단서를 보고 의심되는 것을 모두 고른 뒤 정답을 확인하세요.

    ① 실험 안내 — 온도가 일정할 때 공기의 압력과 부피
    1. 수은 30 cm를 넣은 긴 유리관(한쪽 닫힘)이 방안지를 붙인 판자 위에 있습니다. 처음에는 수평입니다.
    2. 기압계로 기압 H₀를 재서 아래 칸에 적습니다.
    3. 관을 천천히 기울여 자세를 바꿉니다(수직 → 수평 → 거꾸로). 수은이 멈춘 뒤 확대 창에서 읽습니다: 수은기둥의 두 끝의 높이(방안지 눈금)와 공기기둥 길이 L(자).
    4. 끝으로 처음의 수직 자세로 다시 돌아와 L이 변하지 않았는지 확인합니다.
    5. 실험이 끝나면 기압 H₁을 다시 잽니다.
    6. 분석: 압력 P = H + (수은 열린 쪽 끝 높이 − 공기 쪽 끝 높이), V ∝ L. L–1/P 그래프가 원점을 지나는 직선이고 P×L이 일정한지 확인합니다.

    ② 가상 장치

    θ > 0: 닫힌 끝이 아래(열린 끝이 위), θ = 0: 수평, θ < 0: 닫힌 끝이 위(거꾸로). 슬라이더는 놓을 때 적용됩니다.

    ③ 측정값 입력

    높이는 열린 쪽이 위일 때 (열린 쪽 − 공기 쪽)이 +, 거꾸로면 −가 되도록 읽은 값 그대로 입력합니다.

    ④ 분석

    ● 입력한 점 / 빨간 선 = 최소제곱 직선(L 축까지 연장) / 회색 점선 = PV 평균에 맞춘 원점을 지나는 이상선
    행마다 P×L이 평균에서 벗어난 정도(%). 측정한 순서대로입니다.
