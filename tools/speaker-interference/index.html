스피커 간섭·맥놀이 실험 — 소리 발생기

안전 음량은 작게 시작하고, 스피커를 귀에 바짝 대지 않는다. 한 번에 오래(1분 이상) 연속으로 듣지 않는다.
소리 내기 (스테레오 스피커의 왼쪽·오른쪽에서 같은 소리)
Hz
1000 Hz
기기를 스테레오 스피커(또는 이어폰 대신 외부 스피커 2개)에 연결한다. 폰 자체 스피커는 하나뿐이라 간섭 실험이 안 된다. 두 스피커는 소리가 나오는 면이 같은 쪽을 향하게 약 1 m 띄워 놓고, 한쪽 귀로 들으며 가운데에서 옆으로 천천히 걷는다.
예상 위치 계산 (거리를 직접 재어 넣는다)
가운데(0)를 기준으로 좌우로 걸을 때 이론상 소리의 세기 변화(두 스피커를 점 소리원으로 보고, 소리가 퍼지며 약해지는 효과·방 반사는 무시). 파란 점선 = 소리가 가장 작을 곳.
실험 팁
① 진동수는 800~2000 Hz가 좋다(너무 낮으면 소리 작은 곳 폭이 넓어 구분이 어렵다). ② 한쪽 귀를 막고, 고개 방향을 바꾸지 말고 몸 전체를 옆으로 옮긴다. ③ 벽·책상 반사가 많으면 작은 곳도 완전히 조용하진 않다. 복도나 넓은 곳이 좋다. ④ 오른쪽을 반대 위상으로 바꾸면 가운데가 오히려 조용해진다 — 노이즈 캔슬링과 같은 원리. ⑤ 한쪽 스피커만 켜면 위치에 따른 변화가 거의 없는 것을 확인해 비교한다.
맥놀이: 진동수가 조금 다른 두 소리
|f₁ − f₂| = 4 Hz → 1초에 약 4번 커졌다 작아졌다 (10초에 40번)
한 기기로: A·B를 모두 체크하면 두 소리가 섞여 맥놀이가 들린다. 두 기기로: 한 대는 A만, 다른 한 대는 B만 체크해 동시에 재생한다(진동수가 거의 맞으니 서로 가까이 둔다). 빠른 선택:
두 소리를 더한 모양 (이론)
굵은 곡선이 합성파, 얇은 곡선이 포락선(소리 크기 변화). 가로 = 시간 1초.
소리 실험실 앱으로 측정하기
마이크로 듣는 기기에서 소리 실험실 → 맥놀이 탭을 열면 크기 변화 그래프로 맥놀이 진동수를 잴 수 있다.
